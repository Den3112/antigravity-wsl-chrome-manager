# antigravity-wsl-chrome-manager

A developer tool that acts as a bridge, allowing scripts and agents running inside WSL to seamlessly interact with Google Chrome sessions running on the host Windows machine via Chrome DevTools Protocol.

---

## 🚀 Key Features
- Port-forwarding and redirection from WSL to Windows host
- Automated Chrome session detection
- Supports Chrome DevTools Protocol (CDP) debugging
- Minimal configuration overhead

---

## 🛠️ Tech Stack & Setup
- **Core Environment**: Setup instructions depend on the stack.
- Make sure to create a `.env` file for local development configs (do not push keys to git).
